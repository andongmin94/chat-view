### 구현

- 기존 GET `/campaigns`에서 해당 브라우저 관리 계정의 `Creators.describe()`를 읽어 **치지직 재승인 필요 / 송출 역할 필요 / 선택 가능**을 구분한다. 제공자 승인과 유효한 streaming 역할이 모두 있을 때만 기존 선택 form을 보인다. gaming 역할이나 다른 계정의 streaming 승인은 대신하지 않는다.
- 준비 전에는 송출 PC의 기존 OBS 관리 런타임에서 같은 채널·송출 역할을 승인하고 페이지를 다시 확인하도록 안내한다. 게임 PC companion과 그 채팅은 그대로 두며 게임 PC OBS 설치/실행을 요구하지 않는다. GET은 승인·광고를 만들지 않는다.
- 선택 가능은 현재 열린 소켓, 최신 출력 보고, 실제 배너 노출과 다르다. 기존 POST의 제공자·역할·CSRF 검사를 유지하므로 오래된 form도 권한을 우회할 수 없다. 송출 승인 철회 후 재승인/새 보고만으로 캠페인을 자동 선택하지 않는다.
- 선택이 해제돼도 기존 공개 URL·복사 도구·OBS 설정 안내를 유지하며 명시적 재선택을 안내한다. 공개 렌더러·개인 HUD·영상 동의·광고 실적 계산은 변경하지 않는다. 새 의존성·엔드포인트·DB 스키마·호환 경로는 없다.
