## 체크 규칙과 현재 위치

`[x]`는 **명시한 좁은 개발 구현 범위**의 반영과 관련 검사 근거다. 전체 제품·실계정·실제 방송·배포 완료가 아니며 체크 개수로 완성도 퍼센트를 계산하지 않는다.

로그인·승인 복원·역할·로그아웃·출력 보고·시험 캠페인·공개 OBS 소스 위에 **선택한 캠페인의 비지급 활동 근거 → 계정 화면 확인**을 연결했다. 기존 송출 권한으로 수락된 보고만 기존 SQLite에 기록한다. 같은 상태의 연속 보고 두 개 사이만 보수적으로 계산하고, 첫 보고·순번 누락·상태 전환·오래된 보고·연결 교체·시계 불연속은 구분해 계산에서 제외한다. 실제 지속 송출·광고 노출·시청시간의 증명은 아니다.

**다음 사용자 흐름: G5-03의 공식 시청자 표본 수집 → 비지급 추정 시청자 시간 → 기존 계정 화면.** 먼저 이번 원격 통합 검사 결과를 확인한다. 제공자 문서와 이용 권한/사용 가능한 필드를 확인해 구현하고, 없는 표본이나 누락 구간을 0 또는 실측 광고 시청시간으로 바꾸지 않는다. HP·단가·지급 규격과 G3-03의 깨끗한 영상 경로는 별도 미완료다.

- [ ] **G3-03 — OBS 없이 개인 HUD가 빠진 영상 전달.** [미구현·방식 미확정] 캡처카드/출력 구성을 선정·구현한다. OBS 숨김 실행·프로젝터·다른 방송 프로그램으로 우회하지 않는다.

개인 HUD나 출력 활성 보고는 광고 노출/시청 실적이 아니다. 시험 수치를 지급 가능한 실적으로 세지 않는다.

- [x] **G5-01 — 캠페인 목록·선택·중지의 첫 시험 흐름.** 기존 계정/CSRF의 운영자 정의 시험 캠페인 한 개, 송출 승인 결합·철회·재시작 보존·재승인 후 재선택이 있다. 유료 운영/지급 완료가 아니다.

- [ ] **G5-03 — 시청시간 관련 실적 집계.** [부분 구현] 이번에 비지급 출력 활동 구간과 누락 이유를 기록하고 `/campaigns/activity`에서 자기 계정만 확인한다. 송출·녹화·동시·비활성을 구분하며 합집합은 중복 계산하지 않는다. 기록 조회·공개 페이지·미리보기는 시간을 늘리지 않는다. 추정 시청자 시간/실측 광고 시청시간은 null 및 미측정으로 유지한다. 제공자 시청자 표본·권한·노출 계측은 아직 없다.

- [ ] **G5-05 — 유료 운영·정산.** [미구현·규칙 필요] 단가·예산·배분·지급, 중복/초과 방지, 부정 실적·개인정보·광고 고지를 갖춘다.
