SDR·영상만·최대 4096이고 오디오/인코더/네트워크 영상은 없다. 실제 두 화면·게임·다중 GPU·지연/자원·잠금/hotplug·수신 녹화는 미검증이다. [기술 계약](window-video-output.md).
