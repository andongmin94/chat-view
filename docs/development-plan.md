갱신: 2026-09-29 (Asia/Seoul). 이번 변경은 이 문서와 같은 커밋의 **OBS 소스 숨김/복귀 처리와 실제 CEF 장면 합성 검사**다. 시작 기준 `de9db2a9291ea544736d441ae49b03c0d976e9e5`; G5 v1/v2 패치는 이미 통합돼 다시 적용하지 않는다.
이 파일이 유일한 현재 작업 목록이다. 목표는 [PRODUCT.md](../PRODUCT.md), 운영은 [development-workflow.md](development-workflow.md), 책임 구분은 [architecture.md](architecture.md)를 따른다.

> 최종 제품: 한 화면에서 채팅을 읽고 개인 HUD는 시청자에게 노출하지 않으며, 게임 PC에 OBS가 없는 투컴을 지원하는 자체 플랫폼. 선택한 공개 광고의 시청시간 기반 실적을 HP와 광고 수익으로 연결한다.

## 체크 규칙과 현재 위치

`[x]`는 **명시한 좁은 개발 구현 범위**의 반영과 관련 검사 근거다. 전체 제품·실계정·실제 방송·배포 완료가 아니며 체크 개수로 완성도 퍼센트를 계산하지 않는다.

기존 로그인·승인 복원·역할·로그아웃·출력 보고·시험 캠페인 위에 **페이지를 유지하는 OBS 소스의 숨김/복귀**를 연결했다. 숨기면 문구와 조회를 지우며 다시 보일 때 새 응답을 받는다. 페이지 수명과 OBS 가시성을 분리해 뒤늦은 이벤트가 서로를 되살리지 못한다. 비활성 studio preview는 숨김으로 오인하지 않는다. 이 이벤트는 로컬 표시 제어일 뿐 인증이나 실적 근거가 아니다.

**다음 사용자 흐름: G5-02 실제 OBS 장면 검사 결과 확인과 남은 결함 해결.** 이번 전용 flow 검사는 실제 OBS/CEF에서 위치·크기·숨김·캠페인 중지·장면 이탈/복귀·studio preview를 픽셀로 확인한다. 원격 실행 전에는 성공으로 세지 않는다. G3-03의 OBS 없는 깨끗한 영상 전달과 HP/실적·수익은 별도 미완료다.

## G3. 게임 PC에 OBS 없는 투컴

게임 PC에는 게임/챗뷰만, 송출 PC에는 OBS/플러그인이 있으며 개인 HUD가 송출 영상에 섞이지 않아야 한다.

- [x] **G3-01 — 동일 HUD의 OBS 비종속 실행.** 명시적 companion·로그인·중복 방지·종료를 유지한다.
- [ ] **G3-02 — 같은 계정의 채팅·방송 세션 연결.** [부분 구현] 역할 동의·공유·저장 복원·로그아웃과 최근 송출/녹화 활성 상태 전달이 있다. 독립 보고 작업·단기 권한·만료/철회를 처리한다. 방송 이력·장면/소스·다른 출력·실제 두 PC 확인은 남았다. 보고는 시청자 수신/캡처 제외 증명이 아니다.
- [ ] **G3-03 — OBS 없이 개인 HUD가 빠진 영상 전달.** [미구현·방식 미확정] 캡처카드/출력 구성을 선정·구현한다. OBS 숨김 실행·프로젝터·다른 방송 프로그램으로 우회하지 않는다.
- [ ] **G3-04 — 투컴 설치·실사용·영상 확인.** [하드웨어 필요] 지연·자원·재연결과 HUD 없는 녹화를 함께 확인한다.

개인 HUD나 출력 활성 보고는 광고 노출/시청 실적이 아니다. 시험 수치를 지급 가능한 실적으로 세지 않는다.

- [x] **G5-01 — 캠페인 목록·선택·중지의 첫 시험 흐름.** 기존 계정/CSRF의 운영자 정의 시험 캠페인 한 개, 송출 승인 결합·철회·재시작 보존·재승인 후 재선택이 있다. CHZZK #36/#37 계약 검사 통과. 유료 운영/지급 완료가 아니다.

- [ ] **G5-03 — 시청시간 관련 실적 집계.** [미구현·권한/계측 필요] 방송 시간·추정 시청자 시간·실측 시청시간을 구분한다.
