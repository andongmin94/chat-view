## 현재 위치와 체크 규칙

`[x]`는 명시한 좁은 개발 범위와 관련 검사 근거다. 전체 제품·실계정·물리 투컴·배포 완료가 아니며 체크 개수로 완성도 비율을 계산하지 않는다.

기존 companion의 선택 창/별도 SDR 출력에 **1. 시험 패턴 표시 → 2. 수신 확인·게임 출력**을 추가했다. 첫 단계는 게임을 캡처하지 않고 별도 덮개 HWND에 색상 막대·전체 테두리·읽기 전용 표시 번호·움직임만 그린다. 두 번째 단계는 사용자가 수신 화면을 보고 기본 '아니요' 확인을 거쳐야 한다. 2분 만료·선택/화면 변경·중단은 확인을 무효화한다. 번호 입력·기기등록·자동 수신 검증은 없고 서버의 캡처/광고 권한도 바꾸지 않는다. 전환 시 기존 출력창은 유지하고 첫 게임 프레임 전까지 검게 가린다.

직전 Windows #338은 새 수명 검사 변수명의 Windows 매크로 충돌로 컴파일에 실패했다. 해당 이름을 수정했으며 아래 기록에서 이번 검사와 구분한다. **이번 코드의 Windows #339는 마지막 확인 시 빌드/검사 실행 중**이다. 다음 흐름은 **동일 선택 창과 실제 수신 녹화에서 패턴→게임→중지/복귀의 HUD 분리 확인**이다. 하드웨어가 없는 범위를 성공으로 바꾸거나 게임 PC OBS로 우회하지 않는다.
