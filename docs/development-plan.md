## 체크 규칙과 현재 위치

`[x]`는 **명시한 좁은 개발 구현 범위**의 반영과 관련 검사 근거다. 전체 제품·실계정·실제 방송·배포 완료가 아니며 체크 개수로 완성도 퍼센트를 계산하지 않는다.

기존 로그인·갱신·암호화 승인 복원·역할 동의·현재 승인 로그아웃·OBS 출력 보고 위에 **기존 계정 화면의 시험 캠페인 선택과 공개 배너**를 연결한다. 선택은 현재 송출 승인에 묶이며 로그아웃/철회에 함께 삭제된다. 공개 주소는 채팅/계정 권한 없이 시험 문구만 읽는다. 최근 보고가 없거나 중지/만료되면 투명해지고 페이지 복귀에는 새 응답을 요구한다. HP·시청 실적·수익 계산은 아직 없다.

**다음 사용자 흐름: G5-02의 실제 OBS 브라우저 소스 배치·중지·장면 전환 확인.** 이번 계정/HTTP/WebSocket/WebView2 검사 결과부터 확인하고 실패가 있으면 그 경로를 고친다. URL 연결 방식이며 자동 장면 변경은 없다. G3-03의 OBS 없는 깨끗한 영상 경로는 별도 미완료이며 광고나 출력 상태가 이를 대신하지 않는다.

## G5. 광고 선택 → 시청 실적 → HP → 수익

개인 HUD나 출력 활성 보고는 광고 노출/시청 실적이 아니다. 시험 수치를 지급 가능한 실적으로 세지 않는다.

- [ ] **G5-01 — 캠페인 목록·선택·중지.** [구현·통합 검사 대기] 기존 브라우저 계정/CSRF에서 고정 시험 캠페인 한 개를 선택/중지한다. 현재 송출 승인에 결합하고 재시작 시 유효한 선택만 보존한다. 새 송출 승인에는 재선택이 필요하다.
- [ ] **G5-02 — 선택 광고의 별도 OBS 공개 출력.** [부분 구현·검사 대기] 공개 URL/고정 자산/투명 배경/960×180 안내가 있고 사용자가 OBS 브라우저 소스에 배치한다. 최근 송출 역할 보고가 있을 때만 시험 문구를 표시하며 중지/만료/페이지 이탈은 숨긴다. 복귀에는 새 응답을 요구한다. 원클릭 소스 삽입, 실제 OBS 배치·장면 전환·영상 검증은 남았다.
- [ ] **G5-03 — 시청시간 관련 실적 집계.** [미구현·권한/계측 필요] 방송 시간·추정 시청자 시간·실측 광고 시청시간을 구분한다.
- [ ] **G5-04 — 서버 계산 HP·수익 내역.** [미구현·규격 미정] 비지급 시험과 예상/확정 구분부터 만든다. 임의의 HP 0 지급 규칙은 없다.
- [ ] **G5-05 — 유료 운영·정산.** [미구현·운영 규칙 필요] 단가·예산·배분·지급, 중복/초과 방지, 부정 실적·개인정보·광고 고지를 갖춘다.

- **통합 대상:** 이전 미반영 G5 v2 패치의 18개 파일이다. 기존 application/creator/gateway/session DB 위에 캠페인 저장·계정 관리·고정 공개 문서/자산·읽기 전용 렌더러와 검사를 연결한다. 출력 보고/로그아웃/캡처 보호와 의존성 핀은 그대로다. 공개 조회는 제공자 인증/계정 복원/채팅 구독을 시작하지 않는다. 공개 문서에 개인 채팅·계정 ID·인증 자격증명을 전달하지 않는다.

### 다음 세션 재개 지시

OBS 최신 ref에서 지정된 다섯 문서를 순서대로 읽는다. 현재 G5 패치의 코드 반영/관련 CI부터 확인하고 실패를 고친다. 원격 통합이 확인되면 로컬 v1/v2 패치를 다시 적용하지 않는다. 다음은 **실제 OBS 브라우저 소스의 위치·크기·중지·장면 전환 확인**이다. 새 서버/로그인/기기등록/수동 표시키/옛 ZIP을 만들지 않으며 게임 PC에 OBS를 요구하지 않는다. G3-03은 별도 미완료로 유지하고 HP/지급 규칙을 임의로 정하지 않는다. routine과 qualification을 구분한다.

미확정 입력: 비공개 앱/채널 승인, 대표 투컴 배선·기기, HP 단위·귀속·표시/보상 조건, 인프라. 비밀키를 대화/공개 저장소에 넣지 않는다. 입력 부재를 목표 변경이나 독립 구현 중단의 이유로 삼지 않는다.
