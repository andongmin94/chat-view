## 현재 위치와 완료 기준

`[x]`는 명시한 좁은 개발 범위와 실제 근거다. 실계정·물리 투컴·배포 완료와 다르며 체크 개수로 완성도 비율을 계산하지 않는다.

기존 자체 연결창에 **계정·시험 광고·활동 관리** 진입을 추가했다. 현재 연결에 사용한 검증된 서비스의 고정 `/account`만 시스템 브라우저로 열고, 기존 계정 화면의 캠페인/활동 링크를 재사용한다. 편집한 주소·다른 저장 계정은 읽지 않는다. 네이티브 토큰·계정/세션 ID·query·fragment를 URL로 보내거나 관리 화면을 채팅 WebView에 넣지 않는다. 브라우저 열기 실패는 채팅·표시·승인을 중단하지 않으며 자동 재시도하지 않는다.

관리 계정은 **브라우저 로그인**으로 결정된다. 앱 로그인과 동일한 계정임을 보장하지 않고 채널 확인과 브라우저 화면의 캡처 보호 범위를 별도로 안내한다. 브라우저 세션이 없으면 기존 미로그인 안내/401을 유지한다. 재로그인 없이 브라우저 권한까지 복원하는 SSO는 만들지 않았다. 미승인·보호·로그아웃 상태에서는 현재 연결의 관리 버튼을 시작하지 않는다. 표시 중지/외부 페이지 선택 뒤에도 현재 승인으로 복귀 가능한 경우 같은 서비스 진입을 쓸 수 있다.

직전 Windows #345는 빌드 성공, routine **37/38**이며 실제 Control Center에서 같은 연결창을 다시 여는 검사만 실패했다. 이 패널을 완전 불투명 layered 창으로 만들고 처음 보이기 전에도 affinity를 검증하도록 보완했다. 재열기 때 보호가 없으면 거절하는 기존 동작은 유지한다. 이 변경의 Windows 회귀 결과가 나오기 전에는 실패를 종료 처리하지 않는다.

**다음 흐름:** **Windows #346 / 37132307532** 결과/새 실패부터 확인한다. 관리 페이지 진입 후 **브라우저 세션 만료·다른 계정 상태의 명시적 복구 안내**를 기존 인증 흐름에 연결하되, 새 PC 승인·기기등록·표시키를 만들거나 native 권한을 브라우저 관리 권한으로 바꾸지 않는다. D4 Q4/Q5와 물리 영상 확인은 남아 있다.
