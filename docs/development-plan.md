## 체크 규칙과 현재 위치

`[x]`는 **명시한 좁은 개발 구현 범위**의 반영과 관련 검사 근거다. 전체 제품·실계정·실제 방송·배포 완료가 아니며 체크 개수로 완성도 퍼센트를 계산하지 않는다.

기존 로그인·승인 복원·역할·로그아웃·출력 보고·시험 캠페인 위에 **페이지를 유지하는 OBS 소스의 숨김/복귀**를 연결했다. 숨기면 문구와 조회를 지우며 다시 보일 때 새 응답을 받는다. 페이지 수명과 OBS 가시성을 분리해 뒤늦은 이벤트가 서로를 되살리지 못한다. 비활성 studio preview는 숨김으로 오인하지 않는다. 이 이벤트는 로컬 표시 제어일 뿐 인증이나 실적 근거가 아니다. 실제 OBS 32.2.2/CEF에서 장면 합성 검사 13개를 통과했고 PNG도 확인했다.

**다음 사용자 흐름: G5-03 — 선택한 시험 캠페인의 비지급 활동 근거를 서버에 기록하고 계정 화면에서 확인한다.** 기존 출력 보고·캠페인 승인·중지 경로를 재사용한다. 우선 관측 가능한 출력 활성 구간과 중단/누락을 다루고, 공개 페이지 조회나 미리보기·OBS 소스 가시성을 시청자 실적으로 바꾸지 않는다. 시청자 데이터가 없으면 추정 시청자 시간/실측 광고 시청시간은 미측정으로 표시한다. G3-03 깨끗한 영상 전달과 HP·단가·지급 규격은 별도 미완료다.

## G5. 광고 선택 → 시청 실적 → HP → 수익

개인 HUD나 출력 활성 보고는 광고 노출/시청 실적이 아니다. 시험 수치를 지급 가능한 실적으로 세지 않는다.

- [x] **G5-01 — 캠페인 목록·선택·중지의 첫 시험 흐름.** 기존 계정/CSRF의 운영자 정의 시험 캠페인 한 개, 송출 승인 결합·철회·재시작 보존·재승인 후 재선택이 있다. 유료 운영/지급 완료가 아니다.
- [x] **G5-02 — 시험 캠페인의 별도 OBS 공개 소스 흐름.** 공개 URL·고정 자산·960×180 투명 배너를 사용자가 OBS에 배치하고 위치/크기를 확인한다. `f083dc7`의 실제 OBS 32.2.2/CEF 검사에서 13개 장면 합성 PNG로 원래/절반 크기, 숨김·중지·재선택, 장면 복귀·장애, studio preview, 페이지 유지/숨김 시 종료 두 설정을 확인했다. private chat 권한이나 OBS 페이지 권한을 광고에 주지 않는다. 이 체크는 시험 소스와 해당 합성 흐름 한정이며 실제 사용자 방송/녹화 파일·실계정·모든 환경·개인 HUD 제외를 보장하지 않는다. 원클릭 소스 삽입은 없다.
- [ ] **G5-03 — 시청시간 관련 실적 집계.** [다음 구현·권한/계측 필요] 먼저 비지급 활동 근거를 확인하는 흐름을 만들고 출력 활성 시간·추정 시청자 시간·실측 시청시간을 구분한다. 미측정 항목을 0이나 검증된 노출로 바꾸지 않는다.
- [ ] **G5-04 — 서버 계산 HP·수익 내역.** [미구현·규격 미정] 비지급 시험과 예상/확정을 구분한다. 임의의 HP 0 지급 규칙은 없다.
- [ ] **G5-05 — 유료 운영·정산.** [미구현·규칙 필요] 단가·예산·배분·지급, 중복/초과 방지, 부정 실적·개인정보·광고 고지를 갖춘다.

G5 패치를 다시 적용하거나 완료한 source 숨김/복귀를 재작성하지 않는다. **G5-01/G5-02의 좁은 시험 캠페인/OBS 공개 소스 흐름은 위 코드와 검사로 확인됐다. 다음 구현은 G5-03의 비지급 활동 근거 기록 → 기존 계정 화면 확인**이다. 출력 보고가 있는 활성 구간·중지·누락·중복을 다루되 공개 조회/미리보기/소스 이벤트를 광고 실적으로 만들지 않는다. 시청자 시간은 데이터가 있을 때만 해당 추정 또는 실측으로 구분한다. 미확정 입력: 비공개 앱/채널 승인, 대표 투컴 배선·기기, HP 단위·귀속·표시/보상 조건, 인프라. 비밀키를 대화/공개 저장소에 넣지 않는다. 입력 부재를 목표 변경이나 독립 구현 중단의 이유로 삼지 않는다.
