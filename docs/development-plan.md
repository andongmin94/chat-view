### 변경한 동작

- 영상 설정창을 opaque layered HWND로 만들고 최초 표시·재열기에서 `GetWindowDisplayAffinity`까지 확인한다. 기존 `permitted()`의 캐시된 HUD 플래그뿐 아니라 **실제 HUD/영상 설정창의 캡처 제외와 capture-risk**를 다시 확인한다. 실패하면 캡처·패턴·선택·해제 예약을 폐기하고 기존 독립 검정 출력창은 유지한다. 설정창은 숨기며 보호 속성을 임의 복구하지 않는다. 실패 원인과 `보호 복귀 → 목록 새로고침 → 새 대상 선택 → 새 시험 패턴`을 기존 notice/단계에 표시한다.
- 동일 guard를 기존 패널 열기·목록·패턴 그리기·worker 시작·신선한 snapshot의 덮개 해제에 적용한다. 동기 `mask()` 메시지에서 실제 보호가 바뀌어도 돌아온 이전 호출이 패턴이나 WGC를 시작하지 못한다. 늦은 프레임·queued timer·이미 게시된 패널 열기 요청은 새 동의가 아니다. 정상 일반 중지는 기존 대상 선택을 유지하지만 **보호 실패는 선택을 무효화**한다.
- 채팅창 → 영상 설정 요청은 **명령을 보낸 기존 채팅창 자체의 가시성과 캡처 제외**도 확인한다. 이 창만 보호를 잃으면 해당 이동만 거부하고 창을 숨긴다. 건강한 영상 출력·현재 패턴 번호/동의·로그인 승인은 변경하지 않는다. 수신한 영상창은 실행 시 자신의 보호를 다시 확인한다. 영상창 → 채팅창 요청도 전후 보호를 확인하며, 채팅 전용 hint가 영상 notice의 번호나 검정 안내를 덮어쓰지 않는다. 송출 역할에는 게임 PC 버튼/권한을 추가하지 않는다.
