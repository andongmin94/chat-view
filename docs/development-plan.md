## 현재 위치와 완료 기준

`[x]`는 명시한 좁은 개발 범위와 실제 근거다. 실계정·물리 투컴·배포 완료와 다르며 체크 개수로 완성도 비율을 계산하지 않는다.

기존 Control Center의 연결 상태와 기존 자체 연결창의 새 읽기 전용 표시가 같은 상태를 사용한다. **자체 수신, 종료 처리, 자체 표시 중지, 외부 페이지 선택, 현재 승인으로 복귀 요청 가능 여부**를 구분한다. 외부 URL 편집/저장 여부를 실제 표시 선택으로 간주하지 않고 WebViewHost의 현재 선택을 읽는다. 선택은 페이지 로딩 성공이 아니며, 복귀 요청 가능은 서버가 승인을 받아 준다는 보장이 아니다.

복귀 버튼도 같은 상태로 활성화한다. 작업 종료 전·보호 중·로그아웃 중에는 복귀가 활성화되지 않는다. 외부 페이지 적용으로 현재 문서를 바꾼 뒤 상태를 갱신하며, 빈 URL 적용은 외부 페이지로 거짓 표시하지 않는다. 기존 같은 승인 복귀·중지·로그아웃과 독립 영상 미검증 안내를 재사용한다. 새 인증 저장소·키·기기등록·캡처/송출 권한은 없다.

**다음 흐름:** **Windows #345 / 37130157738** 결과와 새 실패를 먼저 확인한다. 그다음 **현재 연결에서 기존 계정·시험 캠페인·비지급 활동 관리 화면을 시스템 브라우저로 여는 진입**을 연결한다. 계정 관리는 기존 브라우저 인증을 사용하며 개인 채팅 WebView에 관리 권한을 넣지 않는다. D4 Q4/Q5 종료 순서와 물리 영상 확인도 미완료로 유지한다.
